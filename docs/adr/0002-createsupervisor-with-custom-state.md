# Use `createSupervisor` with a custom state schema

The Assistant graph is built with `createSupervisor` from `@langchain/langgraph-supervisor`, with a custom state schema (Annotation root) carrying benchmark fields, rather than a hand-rolled `StateGraph` that uses `Command(goto, update)` for routing. This is deliberate: the package's *tool-based hand-off* (the supervisor LLM emits `transfer_to_<worker>` tool calls to delegate) is itself one of the things the benchmark measures — building our own `Command`-based router would route via structured output instead and silently bypass the tool-calling fidelity test. The custom state schema gives us the instrumentation hooks (`outputMode: "full_history"`, streamed updates, `prompts_version`/`model_id` on traces) we need without rebuilding what the maintained package already does correctly.
