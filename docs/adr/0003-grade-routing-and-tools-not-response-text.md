# Grade routing and tools, not Response text

The Score for a Row is a vector across `routing`, `tool_selection`, `tool_args`, `world_state`, and `completion`. The Assistant's natural-language Response is **not** graded in v1. We rejected an LLM-as-judge over the Response because it would inject the judge LLM's variance into the *metric itself* — a benchmark whose scores depend on how a separate model felt about a paragraph that day is not a benchmark, it's a coin flip with a confidence interval. We also rejected templated string assertions over the Response because they constrain the dataset author and turn natural-language quality into a brittle string-matching exercise. Routing + tool calls + world-state mutations are objective, deterministic, and exactly what fails on a small local model: the Response is essentially a summary of work already captured in the other axes. If response-grading becomes valuable later, it should be added as a separate `(δ)` axis alongside the existing five, never replacing them.
